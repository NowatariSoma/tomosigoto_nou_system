序

これは何か

— 静かに始まる

サークル・稽古会・研究会のための運営システムです。 大学の能楽サークルでの実運用から生まれました。メンバーごとの権限管理、稽古と本番のスケジュール、 演目ごとの配役割り当て、会場・稽古場の管理までを、ブラウザひとつで扱えます。

Docker で自分たちのサーバーに立てて使います。データは自分たちの Supabase プロジェクトに置かれ、 外部サービスに預けるのは自分たちで選んだものだけです。

できること

— 展開する

稽古スケジュール

稽古・申合せ・本番の予定を一覧と編集画面で管理。時間枠と会場を紐付けて、次に誰がどこで舞うかをすぐ引けます。

配役の割り当て

演目ごとにシテ方・地謡・囃子の役をメンバーへ割り当て。舞台と役の対応を崩さずに差し替えできます。

メンバー管理

部員の登録・権限・所属パートをまとめて管理。指導者フラグや管理者権限も画面から切り替えられます。

会場と稽古場

キャンパス内外の会場を住所つきで登録し、スケジュールから参照。部屋単位の設定にも対応します。

資料の共有

謡本・録画・連絡資料をメンバーに共有。YouTube 連携で稽古記録の動画も扱えます。

出欠と連絡

稽古ごとの出欠を記録し、Discord Webhook で通知。連絡の抜けを裏方が追いかけずに済みます。

すぐ始める

— 一気に舞い切る

自分たちのサーバーで

# 1. 取得して環境変数を用意
git clone https://github.com/NowatariSoma/tomosigoto_nou_system.git
cd tomosigoto_nou_system
cp .env.example .env
# .env に自分の Supabase プロジェクトの値を設定

# 2. 起動
docker compose up -d

# フロントエンド → http://localhost:3000
# API ドキュメント → http://localhost:8000/docs

必要なのは Docker と、無料枠で始められる Supabase プロジェクトだけです。
