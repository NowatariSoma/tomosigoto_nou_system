# 練習表自動生成システム

## プロジェクト概要
このリポジトリは、同志社大学能部における練習表自動生成システムの開発プロジェクトです。
本システムは、練習表作成業務の効率化、練習機会の公平性向上、練習の質の向上を目的としています。

## 主な機能と目標
- 練習表作成・再生成時間を「秒〜数分」に短縮し、即時共有
- 欠席情報を反映した自動リスケジュールによる練習機会の公平性確保
- アルゴリズムによる監督者ローテーションの最適化
- 閲覧／編集権限の分離と変更履歴・バージョン管理

## プロジェクト構成
本リポジトリは以下のフォルダで構成されています：

- **要件定義/** - システムの要件定義書、ヒアリング内容、設計書方針
- **設計書/** - ドメイン駆動設計に基づいたシステム設計書
- **tickets/** - 開発チケットとタスク管理

## 技術アプローチ
本システムはドメイン駆動設計（DDD）の思想に基づいて設計されています。これにより以下の利点を実現します：
- ユビキタス言語の確立による要件誤解の減少
- バウンデッドコンテキストによる責務の明確化
- ドメインモデル内でのビジネスルールのカプセル化
- テスト容易性の向上
- 拡張性と保守性の確保

## システムアーキテクチャ
本システムはクリーンアーキテクチャを採用し、以下の層で構成されています：
- ユーザーインターフェース層
- API層
- アプリケーション層
- ドメイン層
- インフラストラクチャ層

## ステークホルダー
システムの主なステークホルダーは以下の通りです：
- 部長 (ClubCaptain) - Admin権限
- 作成担当 (Scheduler) - Editor権限
- 部員 (Member) - Viewer / AbsenceReporter権限
- システム管理者 (ITAdmin) - SysAdmin権限
