## 主要機能
1. **認証プロバイダ設定**
   - メールアドレス認証の有効化
   - パスワード認証の設定
   - (オプション) ソーシャル認証の検討
   - Supabase Auth APIの有効化

2. **パスワードポリシー**
   - 最小文字数要件
   - 文字種の複雑さ要件
   - パスワード有効期限
   - パスワードリセットフロー

3. **認証ページカスタマイズ**
   - カスタムロゴと色設定
   - 利用規約とプライバシーポリシーリンク
   - エラーメッセージのカスタマイズ
   - メールテンプレートのカスタマイズ

4. **セッション管理**
   - セッション有効期間の設定
   - リフレッシュトークン設定
   - 同時ログイン制限
   - 自動ログアウト機能

## 実装詳細
### 認証フロー
1. **サインアップフロー**
   - メールアドレスとパスワードによるアカウント作成
   - メール確認リンクの送信
   - メール確認後のアカウント有効化
   - ユーザープロフィール登録への誘導

2. **ログインフロー**
   - メールアドレスとパスワードによるログイン
   - JWTトークンとリフレッシュトークンの発行
   - セッション維持の実装
   - 認証状態の管理

3. **パスワードリセットフロー**
   - パスワードリセットリクエスト
   - リセットリンクのメール送信
   - 新パスワード設定
   - 設定完了通知

4. **ログアウトフロー**
   - アクティブセッションの終了
   - トークンの無効化
   - クライアントストレージのクリア
   - リダイレクト処理

## 主要ファイル
- `supabase/config/auth.json` - Supabase Auth設定ファイル
- `emails/confirmation.html` - メール確認テンプレート
- `emails/reset_password.html` - パスワードリセットテンプレート
- `src/lib/auth/supabaseAuthClient.ts` - 認証クライアントライブラリ
- `src/lib/auth/authHelpers.ts` - 認証ヘルパー関数
- `src/lib/auth/sessionManager.ts` - セッション管理機能
