## 実装詳細
### ロール構造
1. **システム定義ロール**
   - `system_admin`: システム管理者（最高権限）
   - `department_head`: 部長（部門管理権限）
   - `creator`: 作成担当者（スケジュール作成権限）
   - `member`: 一般メンバー（基本アクセス権限）
   - `guest`: ゲスト（閲覧のみ権限）

2. **権限セット**
   - `read`: 読み取り権限
   - `write`: 作成・編集権限
   - `delete`: 削除権限
   - `approve`: 承認権限
   - `assign`: 割り当て権限
   - `admin`: 管理権限

3. **パート別ロール拡張**
   - 各パートの部長ロール
   - パート固有の権限設定
   - パート内のロール階層

## API設計
### ロール管理API
- `GET /api/roles` - ロール一覧取得
- `GET /api/roles/:id` - 特定ロール詳細取得
- `POST /api/roles` - 新規ロール作成（管理者のみ）
- `PUT /api/roles/:id` - ロール更新（管理者のみ）
- `DELETE /api/roles/:id` - ロール削除（管理者のみ）

### ロール割り当てAPI
- `GET /api/members/:id/roles` - メンバーのロール取得
- `POST /api/members/:id/roles` - メンバーにロール割り当て
- `DELETE /api/members/:id/roles/:role_id` - ロール割り当て解除
- `GET /api/roles/:id/members` - ロールを持つメンバー一覧取得

### ロール変更履歴API
- `GET /api/members/:id/role-history` - メンバーのロール変更履歴取得
- `GET /api/audit/roles` - ロール変更監査ログ取得（管理者のみ）
