# BACK-API-001: 認証・認可システム実装

## 概要
練習表自動生成システムのユーザー認証・認可システムを実装します。Supabase Authを活用し、セキュアなJWT認証と適切な権限管理を構築します。

## 詳細
- Supabase Authの設定と実装
- ユーザーロール（部長/作成担当/部員/システム管理者）の設定
- Row Level Security (RLS)ポリシーの実装
- JWT認証と認証トークンの管理
- 権限に基づいた機能制限の実装

## 主要機能
1. **Supabase Auth設定**
   - メールアドレス認証設定
   - パスワードポリシー設定
   - 認証ページカスタマイズ
   - セッション管理設定

2. **JWT認証と更新機能**
   - JWTトークン生成と検証
   - トークンリフレッシュ機能
   - セキュアなトークン保存
   - 認証状態管理

3. **Row Level Security (RLS)ポリシー**
   - テーブルごとのRLSポリシー設定
   - 役割ベースのアクセス制御
   - セキュリティ監査ログ設定
   - 権限分離の実装

4. **ロール管理機能**
   - ロール定義とアサイン機能
   - 権限の継承機能
   - ロール変更履歴管理
   - 緊急時の権限昇格機能
