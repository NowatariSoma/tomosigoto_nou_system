## 主要機能
1. **JWTトークン管理**
   - JWTトークン構造の設計
   - トークン署名と検証
   - トークンペイロード設計
   - トークン有効期限管理

2. **リフレッシュトークン機能**
   - リフレッシュトークン生成
   - トークン更新メカニズム
   - リフレッシュトークン有効期限
   - リフレッシュトークン無効化

3. **セキュアストレージ**
   - ブラウザストレージ戦略
   - HttpOnly Cookie設定
   - ローカルストレージセキュリティ
   - トークン暗号化（必要に応じて）

4. **認証状態管理**
   - ステート管理ライブラリとの連携
   - 認証状態変更の監視
   - 有効期限切れ検出
   - セッション継続処理

## 実装詳細
### JWTワークフロー
1. **トークン発行フロー**
   - ユーザーログイン後のJWT生成
   - アクセストークンとリフレッシュトークンの発行
   - カスタムクレームと標準クレームの設定
   - ストレージへの安全な保存

2. **トークン検証フロー**
   - 署名の検証
   - 有効期限チェック
   - カスタムクレーム検証
   - 無効化リストチェック

3. **トークン更新フロー**
   - リフレッシュトークンの検証
   - 新しいアクセストークンの発行
   - （オプション）リフレッシュトークンのローテーション
   - 更新イベントの通知

4. **エラーハンドリング**
   - 有効期限切れエラー処理
   - 無効トークンエラー処理
   - リフレッシュ失敗処理
   - 再認証要求トリガー
