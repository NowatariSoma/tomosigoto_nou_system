# BACK-DB-001: データベース設計と実装

## 概要
練習表自動生成システムのデータベースモデルを設計し、テーブル定義の作成およびマイグレーションスクリプトの実装を行います。Supabaseを用いたデータベース構築の基盤となるタスクです。

## 詳細
- PostgreSQLテーブル定義の作成とER図の整備
- RLS（Row Level Security）ポリシーの設計と実装
- 主要テーブル間のリレーションシップ定義
- インデックス設計によるクエリ最適化
- 初期データ（シードデータ）の作成

## 依存関係
- 依存するタスクはありません（最初に実施）

## 主要機能
1. **ユーザー・メンバー管理テーブル**
   - ユーザーアカウント情報（認証関連）
   - メンバープロフィール情報
   - 役割とパート所属情報
   - 監督者資格情報

2. **パート・練習内容テーブル**
   - パート定義と必要設備
   - 練習内容テンプレート
   - 難易度と前提条件

3. **スケジュール管理テーブル**
   - 練習スケジュールのバージョン管理
   - 練習セッション情報
   - 監督者割り当て情報
   - スケジュール公開状態管理

4. **会場・設備管理テーブル**
   - 会場基本情報
   - 収容人数と利用可能時間
   - 設備情報
   - 予約状態管理

5. **欠席管理テーブル**
   - 欠席申請情報
   - 申請状態管理
   - 承認履歴
   - 影響分析データ
