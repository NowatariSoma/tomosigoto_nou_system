# FRONT-SCREEN-002.1: カレンダー表示コンポーネント実装

## 概要
練習表自動生成システムのフロントエンドにおいて、スケジュールを直感的に表示するカレンダー表示コンポーネントを実装します。月表示、週表示、日表示の切り替え機能を備え、練習セッションを視覚的に表現する機能を開発します。

## 詳細
- カレンダーUIコンポーネントの実装（月表示/週表示/日表示）
- 練習セッションのカレンダー上での視覚的表現
- ドラッグ&ドロップによるセッション移動機能
- タイムグリッド表示とタイムスロットの視覚化
- カレンダーナビゲーション機能（前後の月/週への移動）

## 主要機能
1. **カレンダービュー切替**
   - 月表示：月全体の練習スケジュールを俯瞰表示
   - 週表示：週間の詳細なタイムスケジュール表示
   - 日表示：特定日の時間枠ごとの詳細表示
   - ビュー切替UI実装

2. **セッション表示**
   - パート別カラーコーディング
   - セッション時間の視覚的表現
   - 複数セッションの重なり表示
   - ツールチップによる簡易情報表示

3. **ドラッグ&ドロップ**
   - セッションの日時変更
   - 時間枠の調整
   - 権限に基づく編集制限
   - 衝突検出と警告表示

4. **タイムグリッド**
   - 時間枠の視覚化
   - 現在時刻のインジケーター
   - 営業時間/非営業時間の視覚的区別
   - グリッド密度調整

5. **ナビゲーション**
   - 月/週の前後移動ボタン
   - 日付ピッカー統合
   - 特定日へのジャンプ機能
   - 「今日」へのショートカット

## 実装アプローチ
### コンポーネント構成
1. **親コンポーネント**
   - `ScheduleCalendar`: カレンダー全体のコンテナ
   - ビュー状態管理（月/週/日）
   - データフェッチングと変換
   - イベントハンドリング

2. **子コンポーネント**
   - `MonthView`: 月表示実装
   - `WeekView`: 週表示実装
   - `DayView`: 日表示実装
   - `SessionCard`: 練習セッション表示カード
   - `TimeGrid`: 時間枠グリッド
   - `CalendarHeader`: ナビゲーションヘッダー

3. **ユーティリティ**
   - `dateUtils`: 日付操作関数
   - `sessionFormatters`: セッションデータ変換
   - `dragDropHandlers`: ドラッグ&ドロップ処理

## 技術選定
- **ベースライブラリ**: Material-UI Grid/Paper コンポーネント
- **カレンダーフレームワーク**: React Big Calendar をベース
- **ドラッグ&ドロップ**: react-dnd または React Big Calendar 内蔵機能
- **日付操作**: date-fns
- **状態管理**: React Context + useReducer
