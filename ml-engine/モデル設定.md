### 2. 各パラメータの意味と計算式

#### 📊 `n_steps` (各環境のステップ数)
```python
# 計算式
n_steps = 環境内での経験収集ステップ数

# 最適値の計算
optimal_n_steps = min(2048, max(256, 512))

# 理由
- 少なすぎる (256以下): GPUが十分に活用されない
- 多すぎる (2048以上): メモリ使用量が増加
- 512: 並列環境とのバランスが良い

# 推奨値の範囲
推奨範囲: 256 ~ 2048
最適値: 512 (並列環境32環境の場合)
```

#### 📊 `batch_size` (バッチサイズ)
```python
# 計算式
batch_size = n_steps × n_envs × 学習効率係数

# 最適値の計算
optimal_batch_size = n_steps × n_envs × 0.5
optimal_batch_size = 512 × 32 × 0.5 = 8,192

# 現在の2048は適切な値
# 推奨値: 1024, 2048, 4096, 8192

# メモリ制限を考慮した計算
max_batch_size = min(optimal_batch_size, メモリ制限)
# RTX 3080 Ti (12GB VRAM) の場合
max_batch_size = min(8192, 4096) = 4096
```

#### 📊 `n_epochs` (エポック数)
```python
# 計算式
n_epochs = データ再利用回数

# 最適値の計算
optimal_n_epochs = min(10, max(4, 6))

# 理由
- 少なすぎる (4以下): 学習が不十分
- 多すぎる (10以上): 過学習のリスク
- 6: 並列環境とのバランスが良い

# 並列環境数との関係
if n_envs >= 16:
    optimal_n_epochs = 6   # 並列環境が多い場合
else:
    optimal_n_epochs = 8   # 並列環境が少ない場合
```

#### 📊 `n_envs` (並列環境数)
```python
# 計算式
n_envs = min(CPUコア数, メモリ制限, 最適並列数)

# 最適値の計算
# Ryzen 9 5950X: 16コア
optimal_n_envs = min(16, 16, 16) = 16

# 理由
- 16コアCPUなら16環境が最適
- メモリ制限を考慮
- プロセス間通信のオーバーヘッドを最小化

# 注意: 32環境は高負荷だが動作中
if n_envs > 16:
    print("注意: 32環境は高負荷ですが、現在動作中です")

```

### 3. 最適化計算の実装

#### 🧮 自動最適化計算スクリプト
```python
def calculate_optimal_params(cpu_cores=16, gpu_memory_gb=12):
    """最適な並列処理パラメータを計算"""
    
    # CPUコア数に基づく最適環境数
    optimal_n_envs = min(cpu_cores, 16)
    
    # 環境数に基づく最適ステップ数
    if optimal_n_envs >= 16:
        optimal_n_steps = 512
    else:
        optimal_n_steps = 1024
    
    # バッチサイズの計算
    optimal_batch_size = optimal_n_steps * optimal_n_envs * 0.5
    
    # GPUメモリ制限を考慮
    max_batch_size = gpu_memory_gb * 256  # 概算
    optimal_batch_size = min(optimal_batch_size, max_batch_size)
    
    # エポック数の計算
    if optimal_n_envs >= 16:
        optimal_n_epochs = 6
    else:
        optimal_n_epochs = 8
    
    return {
        'n_envs': optimal_n_envs,
        'n_steps': optimal_n_steps,
        'batch_size': int(optimal_batch_size),
        'n_epochs': optimal_n_epochs
    }

# 使用例
params = calculate_optimal_params(cpu_cores=16, gpu_memory_gb=12)
print(f"最適パラメータ: {params}")
```
