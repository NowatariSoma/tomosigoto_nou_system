## 2. 設定ファイル形式

### 2.1 環境設定 (configs/environment/env.yaml)

```yaml
# 環境設定（場面ベースシステム対応）

# 固定最大値（観測・行動空間のサイズ）
max_rooms: 10               # 最大部屋数
max_scenes: 20              # 最大場面数
max_timeslots: 4            # 最大時間帯数
max_people: 60              # 最大人数

# 動的範囲（エピソードごとにランダム生成）
dynamic_ranges:
  scenes:
    min: 19                 # 場面数の最小値
    max: 20                 # 場面数の最大値
  rooms:
    min: 6                  # 部屋数の最小値
    max: 8                  # 部屋数の最大値
  people:
    min: 55                 # 人数の最小値
    max: 60                 # 人数の最大値

session_duration: 60        # 基本セッション時間（分）
max_steps: 40               # 最大ステップ数

# 重複行動制御
max_action_history: 20      # 記憶する行動履歴数
repeat_action_penalty: -10.0 # 重複行動のペナルティ

# 監督者制約（無効化）
supervision_rules:
  require_supervisor_in_all_rooms: false  # 無効化
  prevent_self_supervision: false         # 無効化
  max_concurrent_rooms_per_supervisor: 999  # 制限なし
```

**現在の設定での変更点:**
- `max_scenes: 20` (場面数)
- `max_timeslots: 4` (時間帯数)
- `max_people: 60` (最大人数)
- 動的範囲設定の追加

### 2.3 報酬設定 (configs/reward/reward.yaml)

```yaml
# 報酬関数設定（シンプル化された報酬設計）

# 基本報酬
basic_rewards:
  new_assignment: 1.0        # 新規割り当ての報酬
  reassignment: -1.0         # 移動はフラットに小ペナルティ
  repeat_action: -8.0        # 重複行動ペナルティ
  step_penalty: -0.05        # ステップペナルティの絶対値を縮小

# 品質報酬
quality_rewards:
  time_efficiency: 0.0       # 定数シェーピング無効化

# 人物制約ペナルティ
person_constraints:
  person_conflict: -0.05
  terminal_multiplier: 0.0
  priority_penalty_base: 1.0
  priority_penalty_factor: 0.0
  small_overlap_factor: 1
  no_move_bonus_per_person: 3  # 同一時間の人物重複に小さなペナルティ係数

# 完了報酬
completion_rewards:
  scene_completion: 1.0      # 場面完了（増加で進捗促進）

# 報酬の重み付け
reward_weights:
  basic: 1.0
  quality: 1.0
  person_constraints: 1.0
  completion: 1.0
```

**現在の設定での変更点:**
- `new_assignment: 1.0` (新規割り当て報酬)
- `repeat_action: -8.0` (重複行動ペナルティ)
- `step_penalty: -0.05` (ステップペナルティ)
- 監督制約の無効化

## 3. データ形式

### 3.1 場面データ (Scene)

```yaml
scene:
  id: string                  # 場面ID
  name: string                # 場面名（シテ、ワキ、地謡など）
  category: string            # カテゴリ（役柄、楽器、歌）
  priority: int               # 優先度（1-5）
  min_practice_time: int      # 最小練習時間（分）
  max_practice_time: int      # 最大練習時間（分）
  required_skills: list       # 必要なスキル
  compatible_scenes: list     # 同時練習可能な場面
  is_supervisor: bool         # 監督者としての役割
  supervision_scenes: list    # 監督可能な場面
```

### 3.2 練習セッションデータ (Practice Session)

```yaml
session:
  id: string                  # セッションID

  timeslot: int               # 時間帯
  duration: int               # 練習時間（分）
  participants: list          # 参加者リスト
  status: string              # ステータス
```

### 3.3 部屋データ (Room)

```yaml

  id: string                  # 部屋ID
```

## 5. 観測・行動空間

### 5.1 観測空間

```python
observation_space = spaces.Dict({
    "schedule": spaces.MultiBinary((num_timeslots, num_scenes, num_rooms)),
    "scene_status": spaces.Box(low=0, high=1, shape=(num_scenes,)),
    "room_occupancy": spaces.Box(low=0, high=max_people, shape=(num_rooms,)),
    "scene_priorities": spaces.Box(low=0, high=5, shape=(num_scenes,)),
    "action_history": spaces.MultiBinary((max_action_history,))
})
# 時間帯数: num_timeslots = ceil(max_scenes / max_rooms)
```

### 5.2 行動空間


### 6.3 報酬計算

```python
# src/rewards/functions.py
def calculate_reward(self, state, action, done):
    reward = 0.0
    
    # 基本報酬
    if self.is_new_assignment(action):
        reward += self.rewards.basic.new_assignment
    elif self.is_reassignment(action):
        reward += self.rewards.basic.reassignment
    
    # 重複行動ペナルティ
    if self.is_repeat_action(action):
        reward += self.rewards.basic.repeat_action
    
    # 制約違反チェック
    reward += self.check_person_constraints(state)
    
    # 完了報酬
    if done and self.is_all_scenes_assigned(state):
        reward += self.rewards.completion.scene_completion
    
    # ステップペナルティ
    reward += self.rewards.basic.step_penalty
    
    return reward
```
