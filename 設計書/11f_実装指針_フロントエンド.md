# 実装指針：フロントエンド

## 1. 概要

本ドキュメントでは、練習表自動生成システムのフロントエンド実装に関する指針について説明します。このガイドラインは、UI/UXの品質確保、保守性の向上、および開発の効率化を目的としています。

## 2. 技術スタック

### 2.1 コア技術

- **フレームワーク**: React.js 18.x
- **言語**: TypeScript 5.x
- **状態管理**: Redux Toolkit
- **ルーティング**: React Router 6.x
- **UIコンポーネント**: Material-UI (MUI) 5.x
- **フォーム管理**: React Hook Form + Zod

### 2.2 開発ツール

- **ビルドツール**: Vite
- **テストフレームワーク**: Vitest + React Testing Library
- **リンター/フォーマッター**: ESLint + Prettier
- **API連携**: Axios + React Query

## 4. コンポーネント設計

### 4.1 コンポーネント分類

- **プレゼンテーショナルコンポーネント**: UI表示に特化し、状態を持たない
- **コンテナコンポーネント**: ビジネスロジックと状態管理を担当
- **ページコンポーネント**: ルーティングに対応するトップレベルコンポーネント
- **レイアウトコンポーネント**: 共通のページレイアウトを提供

### 4.2 命名規則

- コンポーネントファイル: パスカルケース（例: `ScheduleList.tsx`）
- フックファイル: キャメルケース、`use`プレフィックス（例: `useScheduleData.ts`）
- ユーティリティファイル: キャメルケース（例: `dateFormatter.ts`）

### 4.3 コンポーネント実装例

## 5. 状態管理

### 5.1 状態の分類

- **ローカル状態**: 単一コンポーネント内のみで使用される状態（React useState）
- **グローバル状態**: アプリケーション全体で共有される状態（Redux）
- **サーバー状態**: APIから取得するデータ（React Query）

### 5.2 Redux状態管理

```tsx
// store/schedule/scheduleSlice.ts
import { createSlice, createAsyncThunk } from '@reduxjs/toolkit';
import { scheduleService } from '@/services/scheduleService';
import type { Schedule } from '@/types/schedule';

interface ScheduleState {
  items: Schedule[];
  selectedSchedule: Schedule | null;
  loading: boolean;
  error: string | null;
}

const initialState: ScheduleState = {
  items: [],
  selectedSchedule: null,
  loading: false,
  error: null
};

export const fetchSchedules = createAsyncThunk(
  'schedule/fetchSchedules',
  async (teamId: string) => {
    return await scheduleService.getSchedules(teamId);
  }
);

const scheduleSlice = createSlice({
  name: 'schedule',
  initialState,
  reducers: {
    selectSchedule: (state, action) => {
      state.selectedSchedule = action.payload;
    },
    clearSelectedSchedule: (state) => {
      state.selectedSchedule = null;
    }
  },
  extraReducers: (builder) => {
    builder
      .addCase(fetchSchedules.pending, (state) => {
        state.loading = true;
        state.error = null;
      })
      .addCase(fetchSchedules.fulfilled, (state, action) => {
        state.loading = false;
        state.items = action.payload;
      })
      .addCase(fetchSchedules.rejected, (state, action) => {
        state.loading = false;
        state.error = action.error.message || 'スケジュールの取得に失敗しました';
      });
  }
});

export const { selectSchedule, clearSelectedSchedule } = scheduleSlice.actions;
export default scheduleSlice.reducer;
```

## 6. フォーム実装

### 6.1 基本方針

- React Hook Formを使用してフォーム状態を管理
- Zodを使用してバリデーションスキーマを定義
- フィールド単位のバリデーションと表示

### 6.2 実装例

```tsx
// ScheduleForm.tsx
import React from 'react';
import { useForm } from 'react-hook-form';
import { zodResolver } from '@hookform/resolvers/zod';
import { z } from 'zod';
import { TextField, Button, Grid, MenuItem } from '@mui/material';

// バリデーションスキーマ
const scheduleSchema = z.object({
  practiceDate: z.string().nonempty('練習日は必須です'),
  startTime: z.string().nonempty('開始時間は必須です'),
  endTime: z.string().nonempty('終了時間は必須です')
    .refine(data => data > data.startTime, {
      message: '終了時間は開始時間よりも後である必要があります',
      path: ['endTime']
    }),
  location: z.string().nonempty('場所は必須です'),
  notes: z.string().optional()
});

type ScheduleFormValues = z.infer<typeof scheduleSchema>;

interface ScheduleFormProps {
  initialValues?: Partial<ScheduleFormValues>;
  onSubmit: (data: ScheduleFormValues) => void;
  isSubmitting?: boolean;
}

export const ScheduleForm: React.FC<ScheduleFormProps> = ({
  initialValues,
  onSubmit,
  isSubmitting = false
}) => {
  const { register, handleSubmit, formState: { errors } } = useForm<ScheduleFormValues>({
    resolver: zodResolver(scheduleSchema),
    defaultValues: initialValues || {
      practiceDate: '',
      startTime: '',
      endTime: '',
      location: '',
      notes: ''
    }
  });

  return (
    <form onSubmit={handleSubmit(onSubmit)}>
      <Grid container spacing={2}>
        <Grid item xs={12} md={6}>
          <TextField
            fullWidth
            label="練習日"
            type="date"
            InputLabelProps={{ shrink: true }}
            {...register('practiceDate')}
            error={!!errors.practiceDate}
            helperText={errors.practiceDate?.message}
          />
        </Grid>
        
        <Grid item xs={12} md={3}>
          <TextField
            fullWidth
            label="開始時間"
            type="time"
            InputLabelProps={{ shrink: true }}
            {...register('startTime')}
            error={!!errors.startTime}
            helperText={errors.startTime?.message}
          />
        </Grid>
        
        <Grid item xs={12} md={3}>
          <TextField
            fullWidth
            label="終了時間"
            type="time"
            InputLabelProps={{ shrink: true }}
            {...register('endTime')}
            error={!!errors.endTime}
            helperText={errors.endTime?.message}
          />
        </Grid>
        
        <Grid item xs={12}>
          <TextField
            fullWidth
            label="場所"
            {...register('location')}
            error={!!errors.location}
            helperText={errors.location?.message}
          />
        </Grid>
        
        <Grid item xs={12}>
          <TextField
            fullWidth
            label="備考"
            multiline
            rows={4}
            {...register('notes')}
            error={!!errors.notes}
            helperText={errors.notes?.message}
          />
        </Grid>
        
        <Grid item xs={12}>
          <Button
            type="submit"
            variant="contained"
            color="primary"
            disabled={isSubmitting}
          >
            {isSubmitting ? '保存中...' : '保存'}
          </Button>
        </Grid>
      </Grid>
    </form>
  );
};
```

## 7. APIとの連携

### 7.1 基本方針

- Axiosを使用してAPI呼び出しを行う
- React Queryを使用してサーバー状態を管理
- インターセプターを使用して共通のエラー処理を実装

### 7.2 APIサービス実装例

```tsx
// services/api.ts - 基本的なAPI設定
import axios from 'axios';
import { getAccessToken } from '@/utils/auth';

const api = axios.create({
  baseURL: import.meta.env.VITE_API_BASE_URL,
  headers: {
    'Content-Type': 'application/json'
  }
});

// リクエストインターセプター
api.interceptors.request.use(
  (config) => {
    const token = getAccessToken();
    if (token) {
      config.headers.Authorization = `Bearer ${token}`;
    }
    return config;
  },
  (error) => Promise.reject(error)
);

// レスポンスインターセプター
api.interceptors.response.use(
  (response) => response,
  (error) => {
    // グローバルエラーハンドリング
    if (error.response) {
      const { status } = error.response;
      
      if (status === 401) {
        // 認証エラー処理
        // ログイン画面へリダイレクトなど
      } else if (status === 403) {
        // 権限エラー処理
      } else if (status === 500) {
        // サーバーエラー処理
      }
    }
    
    return Promise.reject(error);
  }
);

export default api;

// services/scheduleService.ts - スケジュール関連API
import api from './api';
import type { Schedule, ScheduleCreateInput } from '@/types/schedule';

export const scheduleService = {
  getSchedules: async (teamId: string): Promise<Schedule[]> => {
    const response = await api.get(`/teams/${teamId}/schedules`);
    return response.data;
  },
  
  getScheduleById: async (id: string): Promise<Schedule> => {
    const response = await api.get(`/schedules/${id}`);
    return response.data;
  },
  
  createSchedule: async (data: ScheduleCreateInput): Promise<Schedule> => {
    const response = await api.post('/schedules', data);
    return response.data;
  },
  
  updateSchedule: async (id: string, data: Partial<Schedule>): Promise<Schedule> => {
    const response = await api.put(`/schedules/${id}`, data);
    return response.data;
  },
  
  deleteSchedule: async (id: string): Promise<void> => {
    await api.delete(`/schedules/${id}`);
  }
};
```

### 7.3 React Queryの使用例

```tsx
// hooks/useSchedules.ts
import { useQuery, useMutation, useQueryClient } from '@tanstack/react-query';
import { scheduleService } from '@/services/scheduleService';
import type { Schedule, ScheduleCreateInput } from '@/types/schedule';

// スケジュール一覧を取得するフック
export const useSchedules = (teamId: string) => {
  return useQuery({
    queryKey: ['schedules', teamId],
    queryFn: () => scheduleService.getSchedules(teamId),
    staleTime: 5 * 60 * 1000, // 5分間キャッシュを新鮮と判断
  });
};

// スケジュール詳細を取得するフック
export const useScheduleDetail = (id: string | undefined) => {
  return useQuery({
    queryKey: ['schedule', id],
    queryFn: () => scheduleService.getScheduleById(id!),
    enabled: !!id, // idが存在する場合のみ実行
  });
};

// スケジュールを作成するフック
export const useCreateSchedule = () => {
  const queryClient = useQueryClient();
  
  return useMutation({
    mutationFn: (data: ScheduleCreateInput) => scheduleService.createSchedule(data),
    onSuccess: (newSchedule) => {
      // チームのスケジュール一覧を無効化して再取得を促す
      queryClient.invalidateQueries({ queryKey: ['schedules', newSchedule.teamId] });
    },
  });
};

// スケジュールを更新するフック
export const useUpdateSchedule = () => {
  const queryClient = useQueryClient();
  
  return useMutation({
    mutationFn: ({ id, data }: { id: string; data: Partial<Schedule> }) => 
      scheduleService.updateSchedule(id, data),
    onSuccess: (updatedSchedule) => {
      // 特定のスケジュール詳細を更新
      queryClient.setQueryData(['schedule', updatedSchedule.id], updatedSchedule);
      // チームのスケジュール一覧を無効化
      queryClient.invalidateQueries({ queryKey: ['schedules', updatedSchedule.teamId] });
    },
  });
};
```

## 8. パフォーマンス最適化

### 8.1 主要最適化手法

- **コンポーネントのメモ化**: `React.memo`、`useMemo`、`useCallback`の適切な使用
- **コード分割**: `React.lazy`と`Suspense`を使用した動的インポート
- **仮想スクロール**: 大量リストの表示に`react-window`や`react-virtualized`を使用
- **画像最適化**: WebPフォーマットの使用、適切なサイズ指定
- **バンドルサイズ最適化**: ツリーシェイキングの活用、不要なライブラリの削除

### 8.2 実装例

```tsx
// LazyLoadedComponent.tsx
import React, { Suspense } from 'react';
import { CircularProgress } from '@mui/material';

// 動的インポートによるコード分割
const ScheduleCalendar = React.lazy(() => import('./ScheduleCalendar'));

export const CalendarPage: React.FC = () => {
  return (
    <Suspense fallback={<CircularProgress />}>
      <ScheduleCalendar />
    </Suspense>
  );
};

// VirtualizedList.tsx - 仮想スクロール実装例
import React from 'react';
import { FixedSizeList } from 'react-window';
import { ScheduleListItem } from './ScheduleListItem';
import type { Schedule } from '@/types/schedule';

interface VirtualizedScheduleListProps {
  schedules: Schedule[];
  onSelectSchedule: (id: string) => void;
}

export const VirtualizedScheduleList: React.FC<VirtualizedScheduleListProps> = ({
  schedules,
  onSelectSchedule
}) => {
  const Row = ({ index, style }: { index: number; style: React.CSSProperties }) => {
    const schedule = schedules[index];
    return (
      <div style={style}>
        <ScheduleListItem 
          schedule={schedule} 
          onClick={() => onSelectSchedule(schedule.id)} 
        />
      </div>
    );
  };

  return (
    <FixedSizeList
      height={400}
      width="100%"
      itemSize={80}
      itemCount={schedules.length}
      overscanCount={5}
    >
      {Row}
    </FixedSizeList>
  );
};
```

## 9. テスト戦略

### 9.1 テストの種類

- **ユニットテスト**: 個別のコンポーネントやフックのテスト
- **インテグレーションテスト**: 複数のコンポーネントが連携する機能のテスト
- **E2Eテスト**: ユーザーフローをシミュレートするテスト
