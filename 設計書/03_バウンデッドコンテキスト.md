# 練習表自動生成システム 設計書：バウンデッドコンテキスト

## コンテキストマップ

本システムは以下の3つの主要バウンデッドコンテキストから構成されます。

```mermaid
graph TD
    AC[Attendance Context]
    SC[Scheduling Context]
    PC[Publishing Context]
    MC[Member Context]
    VC[Venue Context]
    
    AC -->|欠席情報の共有| SC
    SC -->|スケジュール公開通知| PC
    MC -->|メンバー情報| SC
    MC -->|監督者資格| SC
    VC -->|会場情報| SC
    MC -.->|表示名・連絡先| PC
    
    style AC fill:#f9f,stroke:#333,stroke-width:2px
    style SC fill:#bbf,stroke:#333,stroke-width:4px
    style PC fill:#bfb,stroke:#333,stroke-width:2px
    style MC fill:#fbb,stroke:#333,stroke-width:2px
    style VC fill:#bff,stroke:#333,stroke-width:2px
```

### コンテキスト間の関係性

| 関係 | 上流 | 下流 | 統合方式 | データ交換 |
|------|------|------|----------|------------|
| 欠席情報の共有 | Attendance Context | Scheduling Context | 発行-購読型 | 欠席イベント |
| スケジュール公開 | Scheduling Context | Publishing Context | 顧客-サプライヤー | 確定スケジュール |
| メンバー情報提供 | Member Context | Scheduling Context | 共有カーネル | メンバーリスト |
| 監督者資格確認 | Member Context | Scheduling Context | 共有カーネル | 監督資格フラグ |
| 会場情報提供 | Venue Context | Scheduling Context | 顧客-サプライヤー | 会場データ |
| 表示情報連携 | Member Context | Publishing Context | コンフォーミスト | 表示用プロファイル |

## 各コンテキストの責務

### Attendance Context（出欠管理コンテキスト）

```mermaid
classDiagram
    class AbsenceRequest {
        <<AggregateRoot>>
    }
    class AbsenceStatus {
        <<ValueObject>>
    }
    class AbsenceManager {
        <<DomainService>>
    }
    
    AbsenceRequest -- AbsenceStatus
    AbsenceManager --> AbsenceRequest
```

**主な責務**:
- 欠席申請の受付と状態管理
- 申請の承認/拒否ワークフロー
- 欠席理由の集計・分析
- 欠席パターンの検出
- 代替日程の提案

**主要エンティティ**:
- AbsenceRequest（欠席申請）

**主要値オブジェクト**:
- AbsenceStatus（欠席状態）

**提供するインターフェース**:
- IAbsenceService: 欠席申請のCRUD操作
- IAbsenceNotification: 欠席イベント通知

**消費するインターフェース**:
- IMemberQuery: メンバー情報照会
- IScheduleQuery: スケジュール情報照会

### Scheduling Context（スケジューリングコンテキスト）

```mermaid
classDiagram
    class PracticeSchedule {
        <<AggregateRoot>>
    }
    class PracticeSession {
        <<Entity>>
    }
    class ScheduleGenerator {
        <<DomainService>>
    }
    class Rescheduler {
        <<DomainService>>
    }
    class RotationEngine {
        <<DomainService>>
    }
    
    PracticeSchedule *-- PracticeSession
    ScheduleGenerator --> PracticeSchedule
    Rescheduler --> PracticeSchedule
    RotationEngine --> PracticeSession
```

**主な責務**:
- 練習スケジュールの最適生成
- 欠席情報に基づく再スケジューリング
- 監督者の公平な割り当て
- 練習の質の評価と最適化
- 会場の適切な割り当て

**主要エンティティ**:
- PracticeSchedule（練習スケジュール）
- PracticeSession（練習セッション）

**主要値オブジェクト**:
- TimeSlot（時間枠）
- OptimizationScore（最適化スコア）
- RotationPolicy（ローテーションポリシー）

**提供するインターフェース**:
- IScheduleService: スケジュール操作
- IScheduleNotification: スケジュール変更通知
- ISupervisorAssignment: 監督者割り当て

**消費するインターフェース**:
- IAbsenceQuery: 欠席情報照会
- IMemberQuery: メンバー情報照会
- IVenueQuery: 会場情報照会

### Publishing Context（公開コンテキスト）

```mermaid
classDiagram
    class PublishedSchedule {
        <<AggregateRoot>>
    }
    class ScheduleVersion {
        <<ValueObject>>
    }
    class PDFExporter {
        <<DomainService>>
    }
    
    PublishedSchedule -- ScheduleVersion
    PDFExporter --> PublishedSchedule
```

**主な責務**:
- スケジュールのバージョン管理
- 確定版のPDFエクスポート
- 変更履歴の管理
- 公開通知の送信
- 公開スケジュールの管理

**主要エンティティ**:
- PublishedSchedule（公開スケジュール）

**主要値オブジェクト**:
- ScheduleVersion（スケジュールバージョン）
- PublicationStatus（公開状態）

**提供するインターフェース**:
- IPublishService: スケジュール公開操作
- IExportService: エクスポート機能
- IHistoryService: 変更履歴管理

**消費するインターフェース**:
- IScheduleQuery: スケジュール情報照会
- IMemberDisplayInfo: メンバー表示情報

### Member Context（メンバー管理コンテキスト）

```mermaid
classDiagram
    class Member {

    }

        <<ValueObject>>
    }

    }
```

**主な責務**:

**主要エンティティ**:
- Member（メンバー）

**主要値オブジェクト**:

**提供するインターフェース**:

- IRoleService: 役割・権限管理

**消費するインターフェース**:
- なし（他コンテキストへ情報提供する中心的コンテキスト）

## コンテキスト間の連携

### 発行-購読型統合

```mermaid
sequenceDiagram
    participant A as Attendance Context
    participant E as Event Bus
    participant S as Scheduling Context
    
    A->>E: 発行: AbsenceCreatedEvent
    E->>S: 配信: AbsenceCreatedEvent
    S->>S: 欠席情報に基づくスケジュール再計算
    
    A->>E: 発行: AbsenceCanceledEvent
    E->>S: 配信: AbsenceCanceledEvent
    S->>S: スケジュールの影響評価
```

### 顧客-サプライヤー型統合

```mermaid
sequenceDiagram
    participant S as Scheduling Context
    participant P as Publishing Context
    
    S->>S: スケジュール確定
    S->>P: 発行要求(scheduleId, version)
    P->>P: スケジュールコピー作成
    P->>P: PDF生成
    P->>S: 発行完了通知(publishedUrl)
```

### 共有カーネル統合

```mermaid
sequenceDiagram
    participant M as Member Context
    participant S as Scheduling Context
    
    S->>M: メンバー一覧取得
    M->>S: メンバーDTOリスト返却
    
    S->>M: 監督者資格チェック(memberId)
    M->>S: 監督資格情報返却
    
    S->>S: スケジュール生成
```

### コンフォーミスト統合

```mermaid
sequenceDiagram
    participant M as Member Context
    participant P as Publishing Context
    
    P->>M: メンバー表示情報取得(memberIds)
    M->>P: 表示情報DTOリスト返却
    
    P->>P: PDF生成にメンバー情報を統合
```
